# 공개 자료 안내

2026년 11월 7일부터 앱 이름과 시연 화면을 포함하는 제품 포트폴리오로 공개 범위를 갱신했습니다. 이전 익명 개발 기록은 유지하되, 현재 README와 이 문서를 공개 범위의 기준으로 삼습니다.

## 포함한 자료

- 내세금관리 앱 이름, My Tax Manager 영문 소개, 아이콘과 공개 스토어 링크
- 예시 거래와 영수증으로 만든 소개 이미지와 UI 개선 전후 화면
- 개편 계기, 기능 소개, 기술 선택과 문제 해결 과정
- 실제 앱에서 발췌한 선택창 UI 코드·XML과 통합 방법
- 별도로 작성하고 학습용이라고 표시한 집계·선택 상태 예제

## 포함하지 않은 자료

- 서명 키, 비밀번호, 인증 자료, 계정 설정과 로컬 환경 경로
- 구매 주문·지급 내역, 구매자 정보와 실제 사용자 거래·영수증
- 배포 APK·AAB, 원본 앱 전체 소스와 비공개 보고서 PDF
- 저장·이관, 백업 암호화·잠금 등 중요한 운영 구현

화면 속 금액은 예시이며 매출 실적을 나타내지 않습니다. 첫 수익 이야기는 개편 계기만 설명하며 구매자나 주문을 공개하지 않습니다.

`examples/android-ui`는 실제 UI 구현 일부이고, 나머지 예제는 독립적인 학습 코드입니다. 전체 앱 빌드에 필요한 소스와 설정은 포함하지 않았습니다. 원본 앱의 테스트 통과 결과를 이 저장소 전체의 실행 보장으로 해석하지 않습니다.
